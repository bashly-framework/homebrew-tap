# Bashly Homebrew Tap

## Install

```shell
brew tap bashly-framework/tap
brew install bashly
```

Or install the formula directly:

```shell
brew install bashly-framework/tap/bashly
```

## Development

Install [Gembrew](https://github.com/DannyBen/gembrew):

```shell
gem install gembrew
```

Generate the formula:

```shell
gembrew build
```

Open an interactive Homebrew environment (requires docker):

```shell
gembrew shell
```
